## Инфраструктура

| Компонент | Значение |
|-----------|----------|
| **Сервер** | `192.168.1.219` (CentOS/RHEL) |
| **Домен** | `https://it-track.kkeystro.ru` |
| **SSL** | Self-signed (провайдер блокирует порт 80 для Let's Encrypt) |

## 2. Бэкенд (FastAPI + SQLite)

### 2.1. Структура

```
/opt/it-track/backend/
├── app/
│   ├── main.py              # FastAPI приложение + lifespan (seed)
│   ├── config.py            # Pydantic settings
│   ├── database.py          # SQLAlchemy async engine + session
│   ├── models/              # SQLAlchemy модели
│   │   ├── profession.py    # Profession
│   │   ├── question.py      # Question, AnswerOption
│   │   ├── roadmap.py       # Stage, Step
│   │   ├── quiz_session.py  # QuizSession
│   │   └── progress.py      # UserProgress, CompletedStep
│   ├── schemas/             # Pydantic схемы
│   ├── api/                 # Роуты: quiz, recommendations, roadmap, progress
│   ├── services/            # Бизнес-логика: scoring, quiz, recommendation, roadmap, progress
│   └── seed/                # Seed-данные
│       ├── load_data.py     # Загрузка данных (idempotent — чистит БД и пересоздаёт)
│       ├── professions.json # 8 профессий
│       ├── questions.json   # 8 вопросов с весами
│       └── roadmaps.json    # Дорожные карты (124 шага)
└── .env.example
```

### 2.2. API Endpoints

| Метод | Путь | Описание |
|-------|------|----------|
| GET | `/health` | Healthcheck |
| POST | `/api/v1/quiz/start` | Начать тест → session_id + первый вопрос |
| POST | `/api/v1/quiz/answer` | Ответить на вопрос → следующий вопрос или финиш |
| POST | `/api/v1/quiz/finish` | Завершить тест |
| GET | `/api/v1/recommendations/{session_id}` | Топ-3 профессии |
| POST | `/api/v1/recommendations/select` | Выбрать профессию |
| GET | `/api/v1/roadmap/{profession_id}` | Дорожная карта профессии |
| GET | `/api/v1/roadmap/my/{session_id}` | Дорожная карта + прогресс пользователя |
| GET | `/api/v1/progress/{session_id}` | Текущий прогресс |
| PUT | `/api/v1/progress/{session_id}/step/{step_id}` | Отметить шаг выполненным |

### 2.3. Механизм рекомендаций

- Каждый вариант ответа имеет веса для каждой из 8 профессий (1–10 баллов)
- После ответа на все 8 вопросов суммируются баллы по каждой профессии
- Применяется рыночный коэффициент профессии (`market_coefficient`)
- Выдаются топ-3 профессии с обоснованием выбора

## 3. Фронтенд (React + Vite)

### 3.1. Сборка

```bash
cd frontend

# .env — API_URL относительный, идёт через nginx
echo "VITE_API_URL=/api/v1" > .env

# Сборка
npm run build

# Результат в dist/
```

### 3.2. Особенности

- **Retry-логика**: до 2 повторных попыток с exponential backoff при ошибках сети/5xx
- **Прогресс навсегда**: roadmap шаги сохраняются в localStorage (не сбрасываются при перезагрузке страницы)
- **Сброс теста**: при заходе на главную страницу старый session_id удаляется, начинается новый тест

## 4. nginx

### 4.1. Конфиг `/etc/nginx/conf.d/it-track.kkeystro.ru.conf`

```nginx
# HTTP → HTTPS редирект
server {
    listen 80;
    server_name it-track.kkeystro.ru;
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl;
    server_name it-track.kkeystro.ru;

    ssl_certificate /etc/nginx/ssl/it-track.kkeystro.ru.crt;
    ssl_certificate_key /etc/nginx/ssl/it-track.kkeystro.ru.key;

    client_max_body_size 10M;

    # Статика (фронт)
    location / {
        root /opt/it-track/frontend;
        index index.html;
        try_files $uri $uri/ /index.html;
        expires 1y;
        add_header Cache-Control "public, immutable";
    }

    # API (прокси на uvicorn)
    location /api/ {
        proxy_pass http://127.0.0.1:8001;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

### 4.2. SSL (self-signed)

```bash
openssl req -x509 -nodes -days 365 \
  -newkey rsa:2048 \
  -keyout /etc/nginx/ssl/it-track.kkeystro.ru.key \
  -out /etc/nginx/ssl/it-track.kkeystro.ru.crt \
  -subj "/CN=it-track.kkeystro.ru"
```

## 5. Systemd-сервис

### `/etc/systemd/system/it-track-backend.service`

```ini
[Unit]
Description=IT Track Career Compass Backend
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/opt/it-track/backend
ExecStart=/usr/local/bin/uvicorn app.main:app --host 127.0.0.1 --port 8001 --workers 1
Restart=always
RestartSec=5
Environment="DATABASE_URL=sqlite+aiosqlite:////opt/it-track/data/app.db"
Environment="DEBUG=false"

[Install]
WantedBy=multi-user.target
```

```bash
systemctl daemon-reload
systemctl enable it-track-backend
systemctl start it-track-backend
```
