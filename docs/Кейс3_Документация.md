> **Проект:** CenterInvest · Финальный проект для ИТ-траектории  
> **Дата:** 18.05.2026  
> **Стек:** Python (FastAPI) + PostgreSQL + React (TypeScript) + Docker

---

## 1. Бизнес-логика приложения

### 1.1 Идея

Пользователь приходит на сайт, видит яркий лендинг с описанием сервиса.  
Проходит короткий **опрос из 8–10 вопросов**, на основе ответов система подбирает **3 наиболее подходящие IT-профессии** с пояснениями.  

После выбора профессии пользователь получает **персонализированную дорожную карту на 12 месяцев** с пошаговым планом обучения:

- 📖 теория
- 🔧 практика
- 🏆 вехи (milestone)
- 🚀 хакатоны
- 💼 поиск работы

Прогресс сохраняется локально (localStorage) и на сервере (после регистрации).

---

### 1.2 Пользовательский путь (User Flow)

```
[Лендинг] → [Тест (8–10 вопросов)] → [Результаты: топ-3 профессии]
                                              ↓
                                       [Выбор профессии]
                                              ↓
                                    [Дорожная карта на 12 месяцев]
                                              ↓
                              [Выполнение шагов / отметка прогресса]
                                              ↓
                              [Регистрация → прогресс на сервере]
```

### 1.3 Роли пользователей

| Роль       | Описание |
|------------|----------|
| **Гость**  | Может пройти тест, получить рекомендации, начать дорожную карту. Прогресс хранится в localStorage + session_id в куках. |
| **Авторизованный** | Те же возможности + прогресс сохраняется на сервере, доступен с любого устройства. |

## 4. Алгоритм скоринга (ключевая бизнес-логика)

### 4.1 Сбор весов

1. У каждого **варианта ответа** хранятся веса для каждой из 8 профессий.
2. Когда пользователь отвечает — веса выбранных вариантов суммируются в `scores[profession_id]`.

### 4.2 Итоговый расчёт

```
raw_score = Σ(weights) по всем выбранным ответам
final_score = (raw_score²) × market_coefficient

# Нормализация:
if max(final_score) > 0:
    final_score = (final_score / max(final_score)) × 100
```

### 4.3 Market coefficient (агрессивные значения)

| Профессия | Коэффициент | Обоснование |
|-----------|-------------|-------------|
| Frontend | 1.8 | Высокий спрос, низкий порог входа |
| Backend | 1.8 | Высокий спрос, много вакансий |
| Data Science | 1.6 | Престижное направление, высокие зарплаты |
| DevOps | 1.5 | Острый дефицит специалистов |
| UX/UI | 1.3 | Растущий спрос |
| PM | 1.1 | Стабильный спрос |
| Analyst | 0.9 | Умеренный спрос |
| QATester | 0.6 | Низкий порог входа, много конкуренции |

### 4.4 Вопрос 7 — мультивыбор (multiple_choice)

Вопрос про интерес к данным:
- Вопрос **multiple_choice**: можно выбрать несколько вариантов
- Варианты от «совсем не люблю» до «обожаю работать с цифрами»
- Каждый вариант имеет свой набор весов

## 5. Сохранение прогресса

### 5.1 Гость

- `session_id` генерируется при старте теста (UUID)
- Прогресс по шагам дорожной карты сохраняется в **localStorage** под ключом `roadmap_progress_{sessionId}`
- `sessionId` сохраняется в `localStorage` как `sessionId`

### 5.2 Авторизованный пользователь

- При регистрации **передаётся session_id** → привязывается к user_id (через `QuizSession.user_id`)
- При входе на `/roadmap` — запрос `/auth/my-profile` получает `session_id` и `selected_profession` с сервера
- Прогресс по шагам сохраняется в БД (`CompletedStep`)
- При получении карты — прогресс **мержится**: серверные данные + localStorage (local имеет приоритет)

## 9. RoadmapPage — ключевые UX-решения

### 9.1 Загрузка данных (три источника)

```
1. QuizContext (state.sessionId + state.selectedProfession) — если пришёл с теста
2. localStorage (sessionId) — если перезагрузил страницу
3. getMyProfile (авторизованные) — session_id + selected_profession с сервера
```

### 9.2 Прогресс — merge server + local

```typescript
// Шаг 1: получаем completed_steps с сервера
// Шаг 2: загружаем completed_steps из localStorage
// Шаг 3: объединяем — local имеет приоритет (user может отменить отметку)
const merged = new Set([...fromServer, ...fromStorage]);
```

### 9.3 Чекбоксы — ручное управление

Пользователь сам отмечает шаги.  
При отметке:
1. **Оптимистичное обновление** UI (мгновенно)
2. **Сохранение в localStorage** (мгновенно)
3. **PUT-запрос на сервер** (в фоне)
4. При ошибке — **откат** (revert)

### 9.4 Дружественные ошибки

Вместо белого экрана или JSON-ошибки:
- 🗺️ Иконка
- «Нет дорожной карты. Похоже, ты ещё не прошёл тест.»
- Кнопка «🚀 Пройти тест»
- Кнопка «Войти» (если не авторизован)

## 10. Заключение

Приложение реализует полный цикл **профориентации в IT**:

1. **Опрос** → сбор предпочтений пользователя
2. **Скоринг** → агрессивная математика с рыночными коэффициентами
3. **Рекомендации** → топ-3 профессии с пояснениями
4. **Дорожная карта** → пошаговый план на 12 месяцев
5. **Прогресс** → сохраняется локально + на сервере
